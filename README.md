# Семантический дальномер

SEO-инструмент для измерения смысловой близости: насколько страница, её блоки и термины близки к запросу, где проходит коридор топа и какой уровень эмбеддингов нужен под задачу. Всё считается в браузере: тексты никуда не отправляются, ключи API не нужны.

## Режимы

- **Страница и топ** — ваша страница против 2–5 конкурентов: коридор топа по метрикам слова, фразы, блока и документа, индекс 0–100, список действий, покрытие подзапросов, темы и термины топа, которых у вас нет.
- **Слова** — близость терминов к ключу, группы, карта смыслов, соседи ключа, попарная матрица.
- **Страницы сайта** — попарная близость своих страниц и риск каннибализации.
- **Уровни и метрики** — какой уровень эмбеддинга брать под какую задачу, меры близости, шкала моделей, источники.

## Две модели

| | Navec | Нейросеть e5 |
|---|---|---|
| Что это | векторы слов, SIF-усреднение | multilingual-e5-small через Transformers.js |
| Размер | 26 МБ, лежит в папке `model/` | 118 МБ, скачивается с Hugging Face при первом выборе |
| Скорость | мгновенно | несколько секунд на анализ |
| Сильная сторона | быстрые прикидки, соседи слов | понимает контекст и порядок слов |

Обе модели кэшируются браузером после первой загрузки. Числа у моделей разные: сравнивайте показания внутри набора, а не между моделями.

## Структура репозитория

```
index.html        — весь сервис: разметка, стили, код
model/meta.json   — описание файлов модели Navec
model/*.bin       — сжатые векторы, словарь и частоты
README.md         — этот файл
```

## Как обновить

Замените `index.html` новой версией через **Add file → Upload files** и нажмите **Commit changes**. Через 1–2 минуты GitHub Pages опубликует изменения. Папку `model/` трогать не нужно, если не менялась модель.

## Источники и лицензии

- Векторы [Navec](https://github.com/natasha/navec) (проект Natasha, MIT), взяты из spaCy `ru_core_news_lg`; сжаты PCA до 192 измерений и product quantization.
- Частоты слов для SIF-весов: [FrequencyWords](https://github.com/hermitdave/FrequencyWords) (контент CC BY-SA 4.0), по субтитрам OpenSubtitles.
- Нейросеть: [intfloat/multilingual-e5-small](https://huggingface.co/intfloat/multilingual-e5-small) (MIT), ONNX-версия [Xenova](https://huggingface.co/Xenova/multilingual-e5-small), библиотека [Transformers.js](https://huggingface.co/docs/transformers.js).
- Метрики: документация [Gemini Embedding](https://ai.google.dev/gemini-api/docs/embeddings), курс Google по эмбеддингам, документация Yandex AI Studio, патентная заявка Яндекса о гибридном ранжировании (эмбеддинг фраз-кандидатов), SIF (Arora et al., 2017), BM25.
